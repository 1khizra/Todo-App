A simple **To-Do List Application** built with **HTML, CSS, and JavaScript**.  
This app lets you **add, edit, and delete tasks**. Each task is timestamped with the current date and time.

## 🚀 Features
- Add new tasks
- Edit existing tasks
- Delete tasks
- Timestamps using JavaScript’s `toLocaleString()`
- Clean and responsive UI

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript (Vanilla JS)
